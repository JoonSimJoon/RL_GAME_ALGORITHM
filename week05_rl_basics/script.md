### [0:05-0:10] MDP 소개

**[교사]**
강화학습 문제를 수학적으로 어떻게 표현할까요? 바로 **MDP(Markov Decision Process)**를 사용합니다.

**[슬라이드: MDP 5-tuple]**
```
MDP = (S, A, P, R, γ)
```

하나씩 살펴봅시다.

**1. S (State) - 상태**

**[화면: 4x4 격자]**
```
┌───┬───┬───┬───┐
│ S │   │   │   │
├───┼───┼───┼───┤
│   │ X │   │   │
├───┼───┼───┼───┤
│   │   │ X │   │
├───┼───┼───┼───┤
│   │   │   │ G │
└───┴───┴───┴───┘
```

**[교사]**
이 GridWorld에서 상태는 뭘까요?

🎯 **[학생]** "에이전트가 있는 위치요!"

**[교사]**
맞아요! S = {(0,0), (0,1), ..., (3,3)} 총 16개 상태입니다.

**2. A (Action) - 행동**

**[칠판에 화살표 그리기]**
```
↑ (상)
↓ (하)
← (좌)
→ (우)
```

**[교사]**
A = {상, 하, 좌, 우} 4개 행동이 있습니다.

**3. P (Transition Probability) - 전이 확률**

**[교사]**
이게 중요해요! "상" 명령을 내렸을 때 항상 위로 갈까요?

🎯 **[학생]** "벽이 있으면 못 가요!"

**[교사]**
맞아요! 이 GridWorld는 **결정적(deterministic)**입니다.
- 벽이 없으면 100% 위로 이동
- 벽이 있으면 100% 제자리

하지만 **확률적(stochastic)** 환경도 있어요.

**[예시 설명]**
```
미끄러운 바닥:
"상" 명령 → 80% 위, 10% 좌, 10% 우
```

이런 불확실성이 있을 때 P(s'|s,a) < 1입니다.

**4. R (Reward) - 보상**

**[화면에 표시]**
```
목표 도달 (G): +1
장애물 (X): -1
일반 이동: -0.04
```

**[교사]**
왜 일반 이동에 -0.04를 줄까요?

🎯 **[학생]** "너무 오래 걸리지 말라고요?"

**[교사]**
정확합니다! 매 턴마다 작은 패널티를 주면, 에이전트가 빨리 목표를 찾으려고 노력하게 됩니다.

**5. γ (Gamma) - 감가율**

**[교사]**
마지막으로 감가율입니다. 0 ≤ γ < 1

**[칠판에 예시]**
```
지금 당장 100원 vs 1년 후 100원

어느 게 더 가치있나요?
```

🎯 **[학생]** "지금 당장 100원이요!"

**[교사]**
맞아요! 미래 가치는 할인됩니다. γ가 바로 이 할인율입니다.

**[슬라이드]**
```
γ = 0: 당장의 보상만 고려 (근시안적)
γ = 0.9: 적당히 미래도 고려
γ = 0.99: 먼 미래까지 중시 (장기적)
```

### [0:12-0:17] 수익과 가치 함수

**[교사]**
이제 중요한 개념들을 정의해봅시다.

**1. 수익 (Return)**

**[칠판에 적기]**
```
G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + ...
```

**[교사]**
시간 t부터 받을 모든 미래 보상의 할인된 합입니다.

**[예시 계산]**
```
보상 시퀀스: [1, 0, 2, 1]
γ = 0.9

G_0 = 1 + 0.9×0 + 0.9²×2 + 0.9³×1
    = 1 + 0 + 1.62 + 0.729
    = 3.349
```

**[교사]**
여러분도 한번 계산해보세요!

**[학생들 계산 시간 30초]**

**2. 상태 가치 함수 (State Value Function)**

**[교사]**
이제 핵심 질문입니다: **"이 상태가 얼마나 좋은가?"**

**[슬라이드]**
```
V^π(s) = E[G_t | S_t = s]
       = "상태 s에서 시작해서 정책 π를 따를 때의 기대 수익"
```

**[화면: GridWorld 가치 맵]**
```
┌──────┬──────┬──────┬──────┐
│ 0.70 │ 0.76 │ 0.81 │ 0.87 │
├──────┼──────┼──────┼──────┤
│ 0.76 │  X   │ 0.87 │ 0.92 │
├──────┼──────┼──────┼──────┤
│ 0.81 │ 0.87 │  X   │ 0.96 │
├──────┼──────┼──────┼──────┤
│ 0.87 │ 0.92 │ 0.96 │ 1.00 │
└──────┴──────┴──────┴──────┘
```

**[교사]**
목표(G)에 가까울수록 가치가 높죠? 이게 바로 V(s)입니다!

🎯 **[학생]** "왼쪽 위 구석이 왜 0.70인가요?"

**[교사]**
좋은 질문이에요! 왼쪽 위에서 목표까지 가려면 오른쪽으로 3칸, 아래로 3칸... 총 6칸을 가야 해요. 그 동안 계속 -0.04씩 패널티를 받고, 마지막에 +1을 받죠. γ=0.9로 할인하면 약 0.70이 나옵니다.

**3. 행동 가치 함수 (Action Value Function)**

**[칠판에 적기]**
```
Q^π(s, a) = E[G_t | S_t = s, A_t = a]
          = "상태 s에서 행동 a를 한 후 정책 π를 따를 때의 기대 수익"
```

**[교사]**
V는 "상태"의 가치, Q는 "상태-행동 쌍"의 가치입니다.

### [0:17-0:25] 벨만 방정식

**[교사]**
드디어 강화학습의 핵심! **벨만 방정식(Bellman Equation)**입니다.

**[칠판에 크게 적기]**
```
V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a)[R(s,a,s') + γV^π(s')]
```

**[교사]**
와, 복잡해 보이죠? 천천히 뜯어봅시다.

**[칠판 옆에 다이어그램]**
```
       s (현재)
       ↓ a (행동)
      s' (다음)
```

**[단계별 설명]**

**[교사]**
1. π(a|s): 정책에 따라 행동 a를 선택
2. P(s'|s,a): 환경이 다음 상태 s'를 결정
3. R(s,a,s'): 즉각 보상을 받음
4. γV^π(s'): 다음 상태의 할인된 가치

**[직관적 설명]**

**[칠판에 적기]**
```
현재 상태 가치 = (즉각 보상) + (미래 가치)
```

**[교사]**
이게 핵심입니다! 현재 가치는 두 부분으로 나뉩니다:
- 지금 당장 받는 보상
- 미래에 받을 보상 (할인됨)

**[구체적 예시]**

**[화면: 상태 (2,2)에서의 벨만 방정식]**

**[교사]**
상태 (2,2)를 생각해봅시다. 최적 정책은 "우"로 이동입니다.

```
V((2,2)) = R + γV((2,3))
         = -0.04 + 0.9 × 0.96
         = -0.04 + 0.864
         = 0.824
         ≈ 0.81 (반올림)
```

맞죠?

**[벨만 최적 방정식]**

**[교사]**
주어진 정책 π가 아니라, **최선의 행동**을 선택한다면?

**[칠판에 적기]**
```
V*(s) = max_a Σ_{s'} P(s'|s,a)[R(s,a,s') + γV*(s')]
```

**[교사]**
이게 **벨만 최적 방정식**입니다. 모든 행동 중 최대값(max)을 선택합니다!

🎯 **[학생]** "그럼 V*를 알면 최적 정책을 알 수 있나요?"

**[교사]**
완벽한 질문입니다! 그렇습니다!

**[칠판에 적기]**
```
π*(s) = argmax_a Q*(s,a)
      = V*를 최대로 만드는 행동 선택
```

**[재귀적 구조 강조]**

**[교사]**
벨만 방정식의 신기한 점은 **재귀적**이라는 겁니다.

```
V(s)를 계산하려면 → V(s')가 필요
V(s')를 계산하려면 → V(s'')가 필요
...
```

**[화면: 재귀 다이어그램]**

**[교사]**
이 재귀를 어떻게 풀까요? 두 가지 방법이 있어요:
1. **Policy Iteration** (정책 반복)
2. **Value Iteration** (가치 반복)

곧 배울 겁니다!

### [0:30-0:40] Value Iteration 구현

**[교사]**
이제 핵심! **Value Iteration** 알고리즘을 구현합시다.

**[칠판에 의사코드]**
```
1. V(s) = 0으로 초기화
2. 반복:
   for each state s:
     V(s) = max_a Σ P(s'|s,a)[R + γV(s')]
3. 수렴할 때까지
4. 정책 추출
```

**[화면: value_iteration.py 템플릿]**

**[교사]**
핵심 부분을 함께 작성해봅시다.

```python
def value_iteration(env, gamma=0.9, theta=0.001):
    # 초기화
    V = {}
    for r in range(env.grid_size):
        for c in range(env.grid_size):
            V[(r, c)] = 0.0
```

**[교사]**
먼저 모든 상태의 가치를 0으로 초기화합니다.

```python
    iteration = 0
    while True:
        delta = 0
        iteration += 1

        for r in range(env.grid_size):
            for c in range(env.grid_size):
                s = (r, c)

                # 종료 상태는 건너뛰기
                if env.is_terminal(s):
                    continue
```

**[교사]**
모든 비종료 상태에 대해 반복합니다.

```python
                v = V[s]  # 이전 가치 저장

                # 벨만 최적 방정식: max over actions
                max_value = float('-inf')

                for a in range(4):  # 4개 행동
                    # 다음 상태와 보상
                    next_s, reward, _ = env.step(s, a)

                    # Q(s, a) 계산
                    q_value = reward + gamma * V[next_s]

                    max_value = max(max_value, q_value)

                V[s] = max_value
                delta = max(delta, abs(v - V[s]))
```

**[교사]**
각 상태에서 모든 행동의 Q값을 계산하고, 최대값을 선택합니다!

🎯 **[학생]** "delta는 뭐예요?"

**[교사]**
좋은 질문! delta는 가치 변화량입니다. 변화가 작으면 수렴한 거죠.

```python
        print(f"반복 {iteration}: delta = {delta:.4f}")

        if delta < theta:
            break
```

**[교사]**
delta가 충분히 작아지면 멈춥니다.

**[실행!]**

```python
V, policy = value_iteration(env)
```

**[출력]**

## 4부: 이론 2 - Policy Iteration (15분)

### [0:40-0:50] Policy Iteration 설명

**[교사]**
Value Iteration은 간단했죠? 이제 다른 방법, **Policy Iteration**을 배워봅시다.

**[칠판에 비교]**
```
Value Iteration: V를 직접 업데이트
Policy Iteration: π를 직접 업데이트
```

**[Policy Iteration 구조]**

**[칠판에 다이어그램]**
```
π₀ → V^π₀ → π₁ → V^π₁ → π₂ → ... → π*
```

**[교사]**
두 단계를 번갈아가며 수행합니다:

**1단계: 정책 평가 (Policy Evaluation)**

**[칠판에 적기]**
```
V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a)[R + γV^π(s')]
```

**[교사]**
주어진 정책 π에 대해 V^π를 계산합니다.

**[예시]**
```
π: 모든 상태에서 "우"로 이동

V^π를 계산하면:
- (0,0): 우→우→우→하→하→하→목표 = ?
- (0,1): 우→우→하→하→하→목표 = ?
...
```

**[교사]**
이걸 벨만 방정식으로 반복 계산합니다.

**2단계: 정책 개선 (Policy Improvement)**

**[칠판에 적기]**
```
π'(s) = argmax_a Q^π(s,a)
      = argmax_a Σ P(s'|s,a)[R + γV^π(s')]
```

**[교사]**
V^π를 보고, 더 나은 정책 π'를 만듭니다. **탐욕 정책(Greedy Policy)**이라고 해요.

**[직관적 설명]**

**[교사]**
생각해보세요. 모든 상태의 가치를 안다면, 어떻게 행동해야 할까요?

🎯 **[학생]** "가치가 높은 상태로 가면 되죠!"

**[교사]**
정확합니다! 그게 바로 정책 개선입니다.

**[정책 개선 정리 (Policy Improvement Theorem)]**

**[칠판에 적기]**
```
만약 Q^π(s, π'(s)) ≥ V^π(s) for all s
그러면 V^π'(s) ≥ V^π(s) for all s

즉, π' ≥ π (더 좋거나 같음)
```

**[교사]**
정책을 개선하면, 가치도 개선됩니다! 수학적으로 증명 가능해요.

### [0:50-0:55] Policy Iteration 알고리즘

**[칠판에 전체 알고리즘]**
```
1. π를 임의로 초기화 (예: 균등 정책)

2. 반복:
   a. 정책 평가: V^π 계산 (수렴까지)
   b. 정책 개선: π' ← greedy(V^π)
   c. if π' == π: break

3. return π (최적 정책)
```

**[교사]**
Value Iteration보다 단계가 많아 보이지만, 수렴이 훨씬 빠릅니다!

**[수렴 속도 비교]**

**[화면: 표]**
| 알고리즘 | 반복 횟수 | 반복당 시간 | 총 시간 |
|---------|----------|------------|---------|
| Value Iteration | 15-30회 | 빠름 | 중간 |
| Policy Iteration | 3-6회 | 느림 | 중간 |

**[교사]**
Policy Iteration은 반복 횟수가 적지만, 각 반복에서 정책 평가가 오래 걸립니다. 결국 비슷해요!

🎯 **[학생]** "그럼 뭘 써야 하나요?"

**[교사]**
상황에 따라 다릅니다:
- 상태 공간이 작으면: Policy Iteration (정확)
- 상태 공간이 크면: Value Iteration (효율적)
- 대부분: Value Iteration 선호

## 5부: 실습 2 - Policy Iteration 구현 (15분)

### [0:55-1:10] Policy Iteration 코드 작성

**[화면: 템플릿]**

**[1단계: 정책 평가 구현]**

```python
def policy_evaluation(env, policy, gamma=0.9, theta=0.001):
    V = {}
    for r in range(env.grid_size):
        for c in range(env.grid_size):
            V[(r, c)] = 0.0

    while True:
        delta = 0

        for r in range(env.grid_size):
            for c in range(env.grid_size):
                s = (r, c)

                if env.is_terminal(s):
                    continue

                v = V[s]

                # 벨만 기대 방정식
                V[s] = 0
                for a in range(4):
                    # policy[s][a] = 행동 a를 선택할 확률
                    next_s, reward, _ = env.step(s, a)
                    V[s] += policy[s][a] * (reward + gamma * V[next_s])

                delta = max(delta, abs(v - V[s]))

        if delta < theta:
            break

    return V
```

**[교사]**
Value Iteration과 비슷하지만, **max 대신 policy 확률로 가중평균**합니다!

**[2단계: 정책 개선 구현]**

```python
def policy_improvement(env, V, gamma=0.9):
    policy = {}

    for r in range(env.grid_size):
        for c in range(env.grid_size):
            s = (r, c)

            if env.is_terminal(s):
                policy[s] = [0.25, 0.25, 0.25, 0.25]  # 아무거나
                continue

            # 각 행동의 Q값 계산
            q_values = []
            for a in range(4):
                next_s, reward, _ = env.step(s, a)
                q = reward + gamma * V[next_s]
                q_values.append(q)

            # 최대 Q값을 가진 행동 찾기
            best_action = q_values.index(max(q_values))

            # 결정적 정책 (확률 1)
            policy[s] = [0.0, 0.0, 0.0, 0.0]
            policy[s][best_action] = 1.0

    return policy
```

**[교사]**
탐욕 정책입니다. 최선의 행동에 확률 1을 줍니다!

**[3단계: 전체 Policy Iteration]**

```python
def policy_iteration(env, gamma=0.9):
    # 초기 정책: 균등 (모든 행동 25%)
    policy = {}
    for r in range(env.grid_size):
        for c in range(env.grid_size):
            policy[(r, c)] = [0.25, 0.25, 0.25, 0.25]

    iteration = 0
    while True:
        iteration += 1
        print(f"\n=== 반복 {iteration} ===")

        # 정책 평가
        V = policy_evaluation(env, policy, gamma)

        # 정책 개선
        new_policy = policy_improvement(env, V, gamma)

        # 수렴 확인
        if new_policy == policy:
            print("정책이 수렴했습니다!")
            break

        policy = new_policy

    return policy, V
```
