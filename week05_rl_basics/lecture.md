- 게임 규칙을 완전히 알고 있음

### 1.2 새로운 도전: 학습 기반 접근

하지만 실제 세계의 많은 문제는 다음과 같은 특성을 가집니다:

1. **불확실성**: 행동의 결과를 100% 예측할 수 없음
2. **복잡성**: 상태 공간이 너무 커서 완전 탐색 불가능
3. **경험 학습**: 환경과 상호작용하며 점진적으로 개선

예시:
- 로봇이 걷는 법을 배우기
- 자동차가 운전을 학습하기
- 게임 캐릭터가 전략을 개발하기

이런 문제를 해결하기 위해 **강화학습(Reinforcement Learning)**이 등장했습니다.

### 1.3 강화학습이란?

**강화학습**은 에이전트(Agent)가 환경(Environment)과 상호작용하며 **보상(Reward)**을 최대화하는 방법을 학습하는 기계학습의 한 분야입니다.

```
┌─────────┐                    ┌─────────────┐
│         │   Action (a_t)     │             │
│  Agent  │──────────────────> │ Environment │
│         │                    │             │
│         │ <──────────────────│             │
└─────────┘  State (s_t)       └─────────────┘
              Reward (r_t)
```

**핵심 개념**:
- **Agent (에이전트)**: 학습하고 의사결정을 하는 주체
- **Environment (환경)**: 에이전트가 상호작용하는 세계
- **State (상태)**: 환경의 현재 상황
- **Action (행동)**: 에이전트가 취할 수 있는 행위
- **Reward (보상)**: 행동에 대한 피드백 신호

### 1.4 강화학습의 특징

**1. Trial and Error (시행착오)**
- 에이전트는 다양한 행동을 시도
- 좋은 결과를 낸 행동은 강화
- 나쁜 결과를 낸 행동은 약화

**2. Delayed Reward (지연된 보상)**
- 즉각적인 보상이 항상 최선은 아님
- 장기적인 보상을 고려해야 함
- 예: 체스에서 말을 희생해 승리하기

**3. Exploration vs Exploitation (탐색 vs 활용)**
- **탐색**: 새로운 행동을 시도해보기
- **활용**: 알고 있는 최선의 행동 사용
- 균형이 중요!

### 1.5 강화학습 vs 지도학습 vs 비지도학습

| 특성 | 지도학습 | 비지도학습 | 강화학습 |
|------|----------|------------|----------|
| 데이터 | 레이블된 데이터 | 레이블 없는 데이터 | 상호작용 경험 |
| 목표 | 정답 예측 | 패턴 발견 | 보상 최대화 |
| 피드백 | 명시적 정답 | 없음 | 보상 신호 |
| 예시 | 이미지 분류 | 군집화 | 게임 플레이 |

## 2. MDP (Markov Decision Process)

강화학습 문제를 수학적으로 모델링하는 표준 방법이 **MDP**입니다.

### 2.1 MDP의 정의

MDP는 다음 5가지 요소로 정의됩니다: **(S, A, P, R, γ)**

#### 2.1.1 S (State Space) - 상태 공간
- 환경이 가질 수 있는 모든 가능한 상태의 집합
- 예시 (격자 세계): S = {(0,0), (0,1), ..., (3,3)}
- 예시 (체스): S = 모든 가능한 보드 배치

#### 2.1.2 A (Action Space) - 행동 공간
- 에이전트가 취할 수 있는 모든 가능한 행동의 집합
- 예시 (격자 세계): A = {상, 하, 좌, 우}
- 예시 (체스): A = 모든 가능한 말의 이동

#### 2.1.3 P (Transition Probability) - 전이 확률
- P(s' | s, a): 상태 s에서 행동 a를 취했을 때 상태 s'로 전이할 확률
- 확률적 환경: P(s' | s, a) < 1 (불확실성 존재)
- 결정적 환경: P(s' | s, a) = 1 or 0

예시:
```
미끄러운 격자 세계:
- "상"으로 이동 명령
  - 80% 확률로 실제로 위로 이동
  - 10% 확률로 좌로 이동
  - 10% 확률로 우로 이동
```

#### 2.1.4 R (Reward Function) - 보상 함수
- R(s, a, s'): 상태 s에서 행동 a로 s'로 전이할 때 받는 보상
- 때로는 R(s), R(s, a)로 단순화하기도 함

예시:
```
격자 세계 보상:
- 목표 도달: +1
- 장애물 충돌: -1
- 일반 이동: -0.04 (에너지 소모)
```

#### 2.1.5 γ (Discount Factor) - 감가율
- 0 ≤ γ < 1
- 미래 보상의 현재 가치를 할인하는 비율
- γ = 0: 근시안적 (즉각 보상만 고려)
- γ → 1: 장기적 (먼 미래도 중시)

### 2.2 Markov Property (마르코프 성질)

MDP의 핵심 가정:

**"미래는 현재 상태에만 의존하며, 과거 이력과는 무관하다"**

수학적 표현:
```
P(S_{t+1} | S_t, A_t, S_{t-1}, A_{t-1}, ..., S_0, A_0)
  = P(S_{t+1} | S_t, A_t)
```

**직관적 설명**:
- 현재 상태가 과거의 모든 정보를 요약하고 있음
- 의사결정에 필요한 모든 정보가 현재 상태에 담겨있음

예시:
- **마르코프 성질 만족**: 체스 보드의 현재 배치 (과거 이동 기록 불필요)
- **마르코프 성질 위반**: 포커 게임에서 상대의 배팅 패턴 (과거 행동 중요)

### 2.3 에피소드 vs 연속 과정

**에피소드 과정 (Episodic Task)**:
- 명확한 종료 상태가 있음
- 예: 게임 한 판, 미로 탈출
- 에피소드마다 초기화

**연속 과정 (Continuing Task)**:
- 종료 없이 계속 진행
- 예: 주식 거래, 로봇 제어
- γ < 1 필수 (무한 보상 방지)

### 2.4 MDP 예시: 미로 찾기

4x4 격자 세계를 MDP로 모델링해봅시다.

```
┌─────┬─────┬─────┬─────┐
│  S  │     │     │     │  S: 시작 (Start)
├─────┼─────┼─────┼─────┤  G: 목표 (Goal)
│     │  X  │     │     │  X: 장애물
├─────┼─────┼─────┼─────┤
│     │     │  X  │     │
├─────┼─────┼─────┼─────┤
│     │     │     │  G  │
└─────┴─────┴─────┴─────┘
```

**MDP 구성 요소**:
- **S**: 16개 격자 위치 (0,0), (0,1), ..., (3,3)
- **A**: {상, 하, 좌, 우}
- **P**: 결정적 (명령한 방향으로 100% 이동, 벽이면 제자리)
- **R**:
  - 목표 도달: +1
  - 장애물: -1
  - 일반 이동: -0.04
- **γ**: 0.9

## 3. 수익(Return)과 감가율

### 3.1 수익의 정의

**수익(Return) G_t**: 시간 t부터 받을 미래 보상의 총합

```
G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + γ³R_{t+4} + ...
    = R_{t+1} + γG_{t+1}
```

**재귀적 관계**: 현재 수익 = 즉각 보상 + (할인된 미래 수익)

### 3.2 감가율의 역할

**왜 γ를 사용할까?**

1. **수학적 이유**: 무한 시간 동안의 보상 합이 발산하지 않도록
2. **실용적 이유**: 불확실한 미래보다 확실한 현재가 더 가치있음
3. **심리적 이유**: 인간도 미래 보상을 할인함 (현재 편향)

### 3.3 γ 값에 따른 행동 변화

예시: 현재 위치에서 목표까지 3칸 떨어짐

```
경로 A: 즉시 +0.5 보상, 그 다음 턴에 +1 (목표)
경로 B: 3턴 후 +10 보상 (목표)
```

**γ = 0 (근시안적)**:
```
G_A = 0.5 + 0×1 = 0.5
G_B = 0 + 0×0 + 0×0 + 0×10 = 0
→ 경로 A 선택 (즉각 보상만 고려)
```

**γ = 0.9 (장기적)**:
```
G_A = 0.5 + 0.9×1 = 1.4
G_B = 0.9³×10 = 7.29
→ 경로 B 선택 (미래 큰 보상 중시)
```

**γ = 0.99 (매우 장기적)**:
```
G_A = 0.5 + 0.99×1 = 1.49
G_B = 0.99³×10 = 9.7
→ 경로 B 강하게 선호
```

### 3.4 실전 γ 값 선택

| γ 값 | 특성 | 적용 분야 |
|------|------|-----------|
| 0.0 ~ 0.5 | 단기 근시안적 | 즉각 반응 시스템 |
| 0.5 ~ 0.9 | 균형잡힌 | 대부분의 게임 |
| 0.9 ~ 0.99 | 장기 전략적 | 바둑, 체스, 전략 게임 |
| 0.99 ~ 1.0 | 매우 장기적 | 금융, 자원 관리 |

## 4. 정책(Policy)과 가치 함수(Value Function)

### 4.1 정책의 정의

**정책(Policy) π**: 상태를 행동으로 매핑하는 전략

**결정적 정책**: π(s) = a
- 상태 s에서 항상 행동 a를 선택

**확률적 정책**: π(a | s) = P(A_t = a | S_t = s)
- 상태 s에서 행동 a를 선택할 확률

예시:
```
결정적 정책:
π((0,0)) = 우  (항상 오른쪽으로)

확률적 정책:
π(상 | (0,0)) = 0.7
π(우 | (0,0)) = 0.3
(70% 위, 30% 오른쪽)
```

### 4.2 상태 가치 함수 (State Value Function)

**V^π(s)**: 정책 π를 따를 때 상태 s에서 시작한 기대 수익

```
V^π(s) = E_π[G_t | S_t = s]
       = E_π[R_{t+1} + γR_{t+2} + γ²R_{t+3} + ... | S_t = s]
```

**해석**:
- "이 상태가 얼마나 좋은가?"
- 정책 π를 따랐을 때 얻을 평균 수익

예시 (격자 세계):
```
┌──────┬──────┬──────┬──────┐
│ 0.87 │ 0.92 │ 0.96 │  G   │
├──────┼──────┼──────┼──────┤
│ 0.81 │  X   │ 0.92 │ 0.96 │
├──────┼──────┼──────┼──────┤
│ 0.76 │ 0.81 │  X   │ 0.92 │
├──────┼──────┼──────┼──────┤
│ 0.70 │ 0.76 │ 0.81 │ 0.87 │
└──────┴──────┴──────┴──────┘

목표에 가까울수록 가치가 높음!
```

### 4.3 행동 가치 함수 (Action Value Function)

**Q^π(s, a)**: 상태 s에서 행동 a를 선택한 후 정책 π를 따를 때의 기대 수익

```
Q^π(s, a) = E_π[G_t | S_t = s, A_t = a]
          = E_π[R_{t+1} + γV^π(S_{t+1}) | S_t = s, A_t = a]
```

**해석**:
- "이 상태에서 이 행동을 하는 것이 얼마나 좋은가?"

**V와 Q의 관계**:
```
V^π(s) = Σ_a π(a|s) Q^π(s,a)
```

상태 가치 = 모든 가능한 행동의 가치를 정책 확률로 가중평균

### 4.4 최적 가치 함수

**최적 상태 가치 함수 V*(s)**:
```
V*(s) = max_π V^π(s)
```
모든 가능한 정책 중 최고의 가치

**최적 행동 가치 함수 Q*(s, a)**:
```
Q*(s, a) = max_π Q^π(s, a)
```

**최적 정책 π***:
```
π*(s) = argmax_a Q*(s, a)
```
최적 행동 가치를 주는 행동 선택

## 5. 벨만 방정식 (Bellman Equation)

강화학습의 핵심 수식!

### 5.1 벨만 기대 방정식 (Bellman Expectation Equation)

**상태 가치에 대한 벨만 방정식**:
```
V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a) [R(s,a,s') + γV^π(s')]
```

**직관적 해석**:
```
현재 상태의 가치 = (즉각 보상) + (다음 상태의 할인된 가치)
```

**단계별 분해**:
1. π(a|s): 정책에 따라 행동 선택
2. P(s'|s,a): 환경의 확률적 전이
3. R(s,a,s'): 즉각 보상 받음
4. γV^π(s'): 다음 상태의 할인된 가치

### 5.2 벨만 방정식의 시각화

```
       s (현재 상태)
      / \
     /   \
   a1     a2  (행동 선택, 확률 π(a|s))
   /       \
  /         \
s1'         s2'  (다음 상태, 확률 P(s'|s,a))
|           |
R1 + γV(s1') R2 + γV(s2')
```

**재귀적 구조**:
- V(s)를 계산하려면 V(s')가 필요
- V(s')를 계산하려면 V(s'')가 필요
- ...
- 최종 상태까지 재귀

### 5.3 벨만 최적 방정식 (Bellman Optimality Equation)

**최적 상태 가치**:
```
V*(s) = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γV*(s')]
```

**최적 행동 가치**:
```
Q*(s,a) = Σ_{s'} P(s'|s,a) [R(s,a,s') + γ max_{a'} Q*(s',a')]
```

**차이점**:
- 기대 방정식: 주어진 정책 π를 따름
- 최적 방정식: 최선의 행동(max)을 선택

### 5.4 간단한 예시로 이해하기

2상태 MDP:
```
S = {s1, s2}
A = {왼쪽, 오른쪽}
γ = 0.9

s1에서:
  - 왼쪽: s1으로 (R=0)
  - 오른쪽: s2로 (R=1)

s2에서:
  - 왼쪽: s1으로 (R=1)
  - 오른쪽: s2로 (R=0)
```

**벨만 최적 방정식 적용**:
```
V*(s1) = max {
  0 + 0.9×V*(s1),  (왼쪽)
  1 + 0.9×V*(s2)   (오른쪽)
}

V*(s2) = max {
  1 + 0.9×V*(s1),  (왼쪽)
  0 + 0.9×V*(s2)   (오른쪽)
}
```

이를 반복해서 풀면:
```
V*(s1) ≈ 13.6
V*(s2) ≈ 14.3
```

**최적 정책**:
```
π*(s1) = 오른쪽 (s2가 더 가치있음)
π*(s2) = 왼쪽 (s1로 돌아가며 보상 받음)
```

## 6. Policy Iteration (정책 반복)

최적 정책을 찾는 첫 번째 알고리즘!

### 6.1 알고리즘 개요

Policy Iteration은 두 단계를 반복합니다:

1. **정책 평가 (Policy Evaluation)**: 현재 정책의 가치 함수 계산
2. **정책 개선 (Policy Improvement)**: 가치 함수를 기반으로 정책 개선

수렴할 때까지 반복하면 최적 정책 π* 도달!

### 6.2 정책 평가 (Policy Evaluation)

**목표**: 주어진 정책 π에 대해 V^π(s) 계산

**반복 업데이트**:
```
V_{k+1}(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a) [R(s,a,s') + γV_k(s')]
```

**의사코드**:
```python
def policy_evaluation(policy, env, gamma=0.9, theta=0.001):
    V = {s: 0 for s in env.states}  # 가치 초기화

    while True:
        delta = 0
        for s in env.states:
            v = V[s]
            # 벨만 기대 방정식 적용
            V[s] = sum(
                policy[s][a] * sum(
                    env.P[s][a][s_next] * (env.R[s][a][s_next] + gamma * V[s_next])
                    for s_next in env.states
                )
                for a in env.actions
            )
            delta = max(delta, abs(v - V[s]))

        if delta < theta:  # 수렴 조건
            break

    return V
```

### 6.3 정책 개선 (Policy Improvement)

**목표**: V^π를 사용해 더 나은 정책 π' 도출

**탐욕 정책 (Greedy Policy)**:
```
π'(s) = argmax_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γV^π(s')]
       = argmax_a Q^π(s,a)
```

**정책 개선 정리**:
만약 Q^π(s, π'(s)) ≥ V^π(s)이면, π' ≥ π (더 좋거나 같음)

**의사코드**:
```python
def policy_improvement(V, env, gamma=0.9):
    policy = {}

    for s in env.states:
        # 각 행동의 Q값 계산
        q_values = {}
        for a in env.actions:
            q_values[a] = sum(
                env.P[s][a][s_next] * (env.R[s][a][s_next] + gamma * V[s_next])
                for s_next in env.states
            )

        # 최대 Q값을 주는 행동 선택 (탐욕)
        best_action = max(q_values, key=q_values.get)

        # 결정적 정책 생성
        policy[s] = {a: (1.0 if a == best_action else 0.0) for a in env.actions}

    return policy
```

### 6.4 전체 Policy Iteration 알고리즘

```python
def policy_iteration(env, gamma=0.9, theta=0.001):
    # 1. 임의의 정책으로 초기화 (균등 정책)
    policy = {
        s: {a: 1.0/len(env.actions) for a in env.actions}
        for s in env.states
    }

    while True:
        # 2. 정책 평가
        V = policy_evaluation(policy, env, gamma, theta)

        # 3. 정책 개선
        new_policy = policy_improvement(V, env, gamma)

        # 4. 수렴 확인
        if new_policy == policy:
            break

        policy = new_policy

    return policy, V
```

### 6.5 Policy Iteration 예시

4x4 격자 세계에서 실행:

**반복 0 (초기 무작위 정책)**:
```
모든 상태에서 상/하/좌/우 동일 확률 (25%)
V ≈ 0 (모든 상태)
```

**반복 1**:
```

V(목표 근처) > V(멀리 떨어진 곳)
정책 개선 → 목표 방향으로 이동하는 정책
```

**반복 2-5**:
```

정책이 점진적으로 개선
```

**수렴 (반복 6)**:

```
┌───┬───┬───┬───┐
```

### 6.6 Policy Iteration의 특징

**장점**:
- 이론적으로 최적 정책 보장
- 빠른 수렴 (일반적으로 몇 번의 반복)
- 명확한 두 단계 구조

**단점**:
- 정책 평가가 느릴 수 있음 (수렴까지 반복)
- 각 반복마다 모든 상태 업데이트 필요

## 7. Value Iteration (가치 반복)

Policy Iteration의 간소화된 버전!

### 7.1 핵심 아이디어

**Policy Iteration의 문제**:
- 정책 평가가 완전히 수렴할 때까지 기다림
- 시간이 오래 걸림

**Value Iteration의 해결책**:
- 정책 평가를 단 한 번만 수행
- 바로 정책 개선으로 넘어감
- 벨만 최적 방정식을 직접 반복 적용

### 7.2 벨만 최적성 업데이트

```
V_{k+1}(s) = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γV_k(s')]
```

**직관**:
- 각 상태에서 최선의 행동을 선택한다고 가정
- V를 직접 업데이트
- 정책은 V가 수렴한 후 한 번만 추출

### 7.3 Value Iteration 의사코드

```python
def value_iteration(env, gamma=0.9, theta=0.001):
    # 1. 가치 함수 초기화
    V = {s: 0 for s in env.states}

    # 2. 가치 반복
    while True:
        delta = 0

        for s in env.states:
            v = V[s]

            # 벨만 최적 방정식: 모든 행동 중 최대값
            V[s] = max(
                sum(
                    env.P[s][a][s_next] * (env.R[s][a][s_next] + gamma * V[s_next])
                    for s_next in env.states
                )
                for a in env.actions
            )

            delta = max(delta, abs(v - V[s]))

        # 3. 수렴 확인
        if delta < theta:
            break

    # 4. 최적 정책 추출 (한 번만)
    policy = extract_policy(V, env, gamma)

    return V, policy

def extract_policy(V, env, gamma):
    policy = {}

    for s in env.states:
        # 각 행동의 Q값 계산
        q_values = {
            a: sum(
                env.P[s][a][s_next] * (env.R[s][a][s_next] + gamma * V[s_next])
                for s_next in env.states
            )
            for a in env.actions
        }

        # 최선의 행동 선택
        best_action = max(q_values, key=q_values.get)
        policy[s] = best_action

    return policy
```

### 7.4 Value Iteration 실행 예시

**반복 0**:
```
V(s) = 0 (모든 s)
```

**반복 1**:
```
목표 상태: V = 1 (즉각 보상)
목표 인접: V ≈ 0.9 (1 + γ×0)
기타: V ≈ 0
```

**반복 2**:
```
목표 상태: V = 1
목표 인접: V ≈ 0.9
2칸 떨어진 곳: V ≈ 0.81 (γ²)
```

**반복 10 (수렴)**:
```
┌──────┬──────┬──────┬──────┐
│ 0.87 │ 0.92 │ 0.96 │ 1.00 │
├──────┼──────┼──────┼──────┤
│ 0.81 │ -1.0 │ 0.92 │ 0.96 │
├──────┼──────┼──────┼──────┤
│ 0.76 │ 0.81 │ -1.0 │ 0.92 │
├──────┼──────┼──────┼──────┤
│ 0.70 │ 0.76 │ 0.81 │ 0.87 │
└──────┴──────┴──────┴──────┘
```

**정책 추출**:
```
각 상태에서 가장 높은 V를 가진 인접 상태로 이동
→ 최적 정책 완성!
```

### 7.5 Policy Iteration vs Value Iteration

| 특성 | Policy Iteration | Value Iteration |
|------|------------------|-----------------|
| 업데이트 | 벨만 기대 방정식 | 벨만 최적 방정식 |
| 정책 평가 | 수렴까지 반복 | 한 번만 |
| 반복 횟수 | 적음 (5-10회) | 많음 (수십~수백회) |
| 반복당 시간 | 오래 걸림 | 빠름 |
| 전체 시간 | 중간 | 빠름 (일반적) |
| 적용 | 작은 상태 공간 | 큰 상태 공간 |

**실전 선택 기준**:
- 상태 공간이 작고 정확성 중요 → Policy Iteration
- 상태 공간이 크고 속도 중요 → Value Iteration
- 대부분의 경우 Value Iteration 선호

### 8.1 환경 설정

```
┌─────┬─────┬─────┬─────┐
│  S  │     │     │     │
├─────┼─────┼─────┼─────┤
│     │  X  │     │     │
├─────┼─────┼─────┼─────┤
│     │     │  X  │     │

└─────┴─────┴─────┴─────┘

S: 시작 (0, 0)
G: 목표 (3, 3) - 보상 +1, 종료
```

### 8.2 상태 공간

```python
states = [
    (0,0), (0,1), (0,2), (0,3),
    (1,0), (1,1), (1,2), (1,3),
    (2,0), (2,1), (2,2), (2,3),
    (3,0), (3,1), (3,2), (3,3)
]
```

총 16개 상태 (4×4 격자)

### 8.3 행동 공간

```python
actions = [0, 1, 2, 3]
# 0: 상 (↑)
# 1: 하 (↓)
# 2: 좌 (←)
# 3: 우 (→)
```

### 8.4 전이 함수

**결정적 전이**:
```python
def get_next_state(state, action):
    row, col = state

    if action == 0:  # 상
        next_state = (max(0, row-1), col)
    elif action == 1:  # 하
        next_state = (min(3, row+1), col)
    elif action == 2:  # 좌
        next_state = (row, max(0, col-1))
    else:  # 우
        next_state = (row, min(3, col+1))

    return next_state
```

**벽 처리**: 격자를 벗어나는 행동은 제자리

### 8.5 보상 함수

```python
def get_reward(state, action, next_state):
    if next_state == (3, 3):  # 목표
        return +1.0
    elif next_state in [(1, 1), (2, 2)]:  # 장애물
        return -1.0
    else:  # 일반 이동
        return -0.04  # 작은 패널티 (빨리 끝내도록 유도)
```

### 8.6 종료 조건

```python
def is_terminal(state):
    return state == (3, 3) or state in [(1, 1), (2, 2)]
```

### 8.7 완전한 MDP 정의

```python
class GridWorld:
    def __init__(self):
        self.grid_size = 4
        self.start = (0, 0)
        self.goal = (3, 3)
        self.obstacles = [(1, 1), (2, 2)]

        self.states = [
            (r, c) for r in range(self.grid_size)
            for c in range(self.grid_size)
        ]

        self.actions = [0, 1, 2, 3]  # 상하좌우

        self.gamma = 0.9

    def step(self, state, action):
        """상태 전이 및 보상 반환"""
        next_state = self._get_next_state(state, action)
        reward = self._get_reward(state, action, next_state)
        done = self._is_terminal(next_state)
        return next_state, reward, done
```

## 9. 쥐를 잡자 게임의 MDP 모델링

### 9.1 게임 규칙 복습

**보드**:
- 7×11 격자
- 고양이 시작: (3, 1)
- 쥐 시작: (3, 9)

**게임 진행**:
1. 고양이 이동 (1칸)
2. 쥐 이동 (1칸)
3. 고양이가 쥐를 잡으면 고양이 승
4. 50턴 안에 못 잡으면 쥐 승

**특수 규칙**:
- 벽 부딪히면 제자리
- 교차 이동 불가 (swap)

### 9.2 상태 공간 설계

**상태 s = (cat_pos, mouse_pos, turn)**

```python
S = {
    ((r_c, c_c), (r_m, c_m), t)
    for r_c in range(7)
    for c_c in range(11)
    for r_m in range(7)
    for c_m in range(11)
    for t in range(50)
}
```

**상태 공간 크기**: 7 × 11 × 7 × 11 × 50 = 296,450 상태!

**실제로는 더 적음**:
- 고양이와 쥐가 같은 위치 불가
- 대칭성 활용 가능

### 9.3 행동 공간

**고양이 관점 (우리가 제어)**:
```python
A_cat = {상, 하, 좌, 우, 정지}  # 5개 행동
```

**쥐 행동 (환경의 일부)**:

```python
A_mouse = {상, 하, 좌, 우, 정지}  # 5개 행동
```

**결합 행동 공간**: 5 × 5 = 25개
- 하지만 우리는 고양이만 제어하므로 실제로는 5개

### 9.4 전이 함수

**쥐의 정책을 알고 있다면**:
```python
P(s' | s, a_cat) = π_mouse(a_mouse | s)
```

**쥐의 정책을 모른다면**:
- 모든 쥐 행동 확률 균등: π_mouse(a) = 1/5
- 또는 쥐가 최적으로 도망간다고 가정

**예시**:
```
상태 s: 고양이(3,1), 쥐(3,9)
행동: 고양이가 우로 이동

다음 상태들:
- 쥐가 좌로: s' = (3,2), (3,8) - 확률 1/5
- 쥐가 상으로: s' = (3,2), (2,9) - 확률 1/5
- ...
```

### 9.5 보상 함수

**고양이 관점**:
```python
def get_reward(state, action, next_state):
    cat_pos, mouse_pos, turn = next_state

    if cat_pos == mouse_pos:  # 쥐 잡음
        return +100
    elif turn >= 50:  # 시간 초과
        return -100
    else:
        # 거리 기반 보상 (선택적)
        distance = abs(cat_pos[0] - mouse_pos[0]) + abs(cat_pos[1] - mouse_pos[1])
        return -distance * 0.1  # 가까워질수록 좋음
```

**보상 설계의 중요성**:
- 너무 희소하면 학습 어려움 (잡았을 때만 보상)
- 중간 보상 추가 (거리 감소 등)
- 하지만 중간 보상이 최종 목표와 어긋나면 안 됨!

### 9.6 감가율 선택

```python
γ = 0.95  # 장기적 전략 필요
```

**이유**:
- 게임이 최대 50턴까지 진행
- 초기 행동이 나중 결과에 영향
- 높은 γ로 장기 계획 유도

- **Prioritized Sweeping**: 중요한 상태 먼저 업데이트
- **Real-Time Dynamic Programming**: 에이전트가 방문하는 상태만 업데이트
- **Partial Observable MDP (POMDP)**: 상태를 완전히 관찰할 수 없는 경우

### 11.3 실제 응용 사례
- **로보틱스**: 로봇 경로 계획, 제어
- **자율주행**: 차선 변경, 주행 전략
- **게임**: 체스, 바둑, 비디오 게임
- **금융**: 포트폴리오 최적화, 거래 전략
- **에너지**: 전력망 관리, 배터리 충전 전략

### 11.4 구현 팁
- 시각화가 중요: 가치 함수와 정책을 항상 그림으로 확인
- 작은 문제부터: 2×2 격자로 시작해서 점진적으로 확대
- 수렴 조건 체크: delta < theta 외에도 최대 반복 횟수 설정
- 버그 디버깅: 벨만 방정식을 직접 손으로 계산해보고 코드와 비교
