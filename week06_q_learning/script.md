## 이론 1: Q-Learning 알고리즘 (15분)

### [00:05-00:08] Q-함수 소개

**교사**: (슬라이드 전환) 먼저 Q-함수가 뭔지 알아야 해요.

지난주에 배운 가치함수 V(s), 기억하나요?

**학생**: V(s)는 상태 s의 가치요!

**교사**: 맞아요. 그런데 V(s)는 "이 상태가 얼마나 좋은지"만 말해줘요. 어떤 행동을 해야 하는지는 안 알려주죠.

Q-함수는 좀 더 구체적이에요. (칠판에 씀)

```
Q(s, a) = 상태 s에서 행동 a를 했을 때 기대되는 총 보상
```

예를 들어볼게요. 게임 상황이 있다고 합시다.

```
Q(현재위치, 왼쪽) = 10
Q(현재위치, 오른쪽) = 15
Q(현재위치, 위) = 3
Q(현재위치, 아래) = 8
```

어떤 행동을 해야 할까요?

**학생**: 오른쪽이요! 15로 제일 크니까!

**교사**: 정확해요! Q-함수를 알면 정책을 바로 만들 수 있어요.

```python
π(s) = argmax_a Q(s, a)  # Q값이 제일 큰 행동 선택
```

이게 Q-함수의 강력한 점이에요.

### [00:08-00:12] Q-Learning 업데이트 규칙

**교사**: 그럼 Q-함수를 어떻게 학습할까요? (칠판에 큰 수식 씀)

```
Q(s,a) ← Q(s,a) + α[R + γ·max Q(s',a') - Q(s,a)]
```

하나씩 뜯어볼게요. 너무 겁먹지 마세요!

**(α 설명)**

**교사**: α는 학습률이에요. 0.1 정도로 생각하면 돼요. 새로운 정보를 얼마나 빠르게 받아들일지 결정합니다.

- α = 0.01: 천천히 학습 (안정적)
- α = 0.5: 빠르게 학습 (불안정할 수 있음)

**(R 설명)**

**교사**: R은 실제로 받은 보상이에요. 게임에서 점수를 얻었다면 그 점수가 R이죠.

**(γ 설명)**

**교사**: γ는 할인율이에요. 0.99 정도로 많이 써요. 미래 보상을 얼마나 중요하게 볼지 결정합니다.

- γ = 0: 눈앞의 보상만 중요
- γ = 0.99: 먼 미래까지 고려

**(max Q(s',a') 설명)**

**교사**: 이게 핵심이에요! 다음 상태 s'에서 가능한 모든 행동 중 **가장 큰 Q값**을 사용합니다.

예를 들어볼게요. (칠판에 그림 그림)

```
현재 상태 s에서 행동 a를 함
→ 보상 R=5 받음
→ 다음 상태 s'로 이동

s'에서 가능한 행동들:
  Q(s', 왼쪽) = 8
  Q(s', 오른쪽) = 12  ← 최대값
  Q(s', 위) = 5
  Q(s', 아래) = 7

max Q(s') = 12
```

그럼 업데이트는?

```
현재 Q(s,a) = 10이었다고 하면,
α = 0.1, γ = 0.9

새로운 추정값 = R + γ·max Q(s') = 5 + 0.9×12 = 15.8
현재 추정값 = Q(s,a) = 10
차이 (TD Error) = 15.8 - 10 = 5.8

업데이트:
Q(s,a) = 10 + 0.1×5.8 = 10.58
```

**학생**: 아, Q값이 올라갔네요!

**교사**: 맞아요! 예상보다 좋았으니까 Q값을 올린 거예요. 반대로 예상보다 나빴으면 Q값을 낮췄을 거예요.

### [00:12-00:15] 알고리즘 전체 흐름

**교사**: 이제 전체 알고리즘을 보죠. (슬라이드로 의사코드 보여줌)

```python
# 1. 초기화
Q(s, a) = 0 for all s, a

# 2. 여러 에피소드 반복
for episode in range(많이):
    state = 시작상태

    while 게임이 안 끝났으면:
        # 3. 행동 선택 (ε-greedy)
        if random() < ε:
            action = 랜덤
        else:
            action = argmax Q(state)

        # 4. 행동 실행
        next_state, reward = env.step(action)

        # 5. Q 업데이트
        max_next_q = max(Q[next_state])
        Q[state][action] += α * (reward + γ*max_next_q - Q[state][action])

        # 6. 상태 전이
        state = next_state
```

**교사**: 여기서 중요한 포인트!

1. **ε-greedy**: 가끔은 랜덤으로 행동해서 새로운 걸 시도 (탐험)
2. **max Q**: 업데이트할 때는 최선의 행동 가정 (활용)

이 두 가지가 다르다는 게 Q-Learning의 특징이에요. 이걸 **Off-policy**라고 해요.

**학생**: 근데 왜 랜덤으로도 행동해요?

**교사**: 좋은 질문! 만약 계속 최선의 행동만 한다면? 새로운 길을 발견할 수 없어요. 혹시 더 좋은 방법이 있을 수도 있는데 못 찾는 거죠.

식당 비유로 들자면:
- 활용: 아는 맛집만 가기
- 탐험: 새로운 식당 시도하기

둘 다 필요해요! 그래서 ε-greedy를 쓰는 거예요. 처음엔 많이 탐험하다가 (ε=1.0), 점점 줄여나가죠 (ε→0.01).

**교사**: 자, 이론은 이 정도로 하고! 실제로 동작하는 걸 보면서 이해해봅시다.

## 실습 1: FrozenLake Q-Learning (15분)

### [00:15-00:17] FrozenLake 환경 소개

**교사**: (화면 공유) 자, 이게 FrozenLake 환경이에요.

```
S F F F
F H F H
F F F H
H F F G
```

**교사**:
- S: 시작점
- F: 안전한 얼음
- H: 구멍 (빠지면 게임 오버)
- G: 목표 (도착하면 성공!)

얼어붙은 호수를 건너서 목표에 도달하는 게임이에요. 구멍에 빠지지 말아야 해요.

행동은 4가지:
- 0: 왼쪽
- 1: 아래
- 2: 오른쪽
- 3: 위

간단하죠? 그런데 `is_slippery=True`로 하면 미끄러워서 의도한 방향으로 안 갈 수도 있어요. 일단 오늘은 `False`로 시작할게요.

### [00:17-00:22] 코드 설명 및 실행

**교사**: (q_learning_frozenlake.py 파일 열기) 코드를 같이 볼게요.

```python
import gymnasium as gym
import numpy as np
import random

# 환경 생성
env = gym.make('FrozenLake-v1', is_slippery=False)

# Q-table 초기화
Q = np.zeros((16, 4))  # 16 상태, 4 행동
```

**교사**: Q-table이 보이죠? 16×4 크기예요. 모든 (상태, 행동) 쌍의 Q값을 저장합니다.

처음엔 전부 0으로 시작해요. 아무것도 모르니까요!

```python
# 하이퍼파라미터
alpha = 0.1      # 학습률
gamma = 0.99     # 할인율
epsilon = 1.0    # 초기 탐험률
epsilon_min = 0.01
epsilon_decay = 0.995

num_episodes = 10000
```

**교사**: 하이퍼파라미터 설정이에요. 이 값들을 나중에 바꿔가며 실험해볼 거예요.

```python
# 학습 루프
for episode in range(num_episodes):
    state, _ = env.reset()
    done = False
    total_reward = 0

    while not done:
        # ε-greedy 행동 선택
        if random.random() < epsilon:
            action = env.action_space.sample()  # 랜덤
        else:
            action = np.argmax(Q[state])  # 최선

        # 환경 step
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated

        # Q-Learning 업데이트
        best_next_q = np.max(Q[next_state]) if not done else 0
        td_error = reward + gamma * best_next_q - Q[state, action]
        Q[state, action] += alpha * td_error

        state = next_state
        total_reward += reward

    # ε 감소
    epsilon = max(epsilon_min, epsilon * epsilon_decay)
```

**교사**: 이게 전부예요! 우리가 아까 본 알고리즘 그대로죠?

자, 실행해볼게요!

**(프로그램 실행)**

```
Episode 0: ε=1.000, Success=0/100 (0.0%)
Episode 500: ε=0.082, Success=67/100 (67.0%)
Episode 1000: ε=0.007, Success=89/100 (89.0%)
Episode 2000: ε=0.010, Success=95/100 (95.0%)
...
학습 완료! 최종 성공률: 98.0%
```

**학생**: 와, 성공률이 올라가요!

**교사**: 그렇죠! 처음엔 0%였는데 학습하면서 98%까지 올라갔어요.

여기서 주목할 점:
- Episode 0: ε=1.0 → 완전 랜덤, 성공률 0%
- Episode 500: ε=0.08 → 거의 학습 완료, 성공률 67%
- Episode 2000: ε=0.01 → 최소값 도달, 성공률 98%

ε가 줄어들면서 점점 똑똑해지는 게 보이죠?

## 이론 2: SARSA와 비교 (10분)

### [00:30-00:35] SARSA 알고리즘

**교사**: (다시 앞으로) 자, 이제 Q-Learning의 형제인 SARSA를 배워볼게요.

SARSA = **S**tate **A**ction **R**eward **S**tate **A**ction

Q-Learning과 거의 똑같은데, 딱 한 줄만 달라요. (칠판에 두 수식 나란히 씀)

```
Q-Learning: Q(s,a) ← Q(s,a) + α[R + γ·max Q(s',a') - Q(s,a)]
                                           ^^^^^^^^^^^^

SARSA:      Q(s,a) ← Q(s,a) + α[R + γ·Q(s',a') - Q(s,a)]
                                        ^^^^^^^^
```

**교사**: 차이 보이죠?

- Q-Learning: **max Q(s')** → 최선의 행동 가정
- SARSA: **Q(s', a')** → 실제로 한 행동 사용

**학생**: 무슨 차이예요?

**교사**: 좋은 질문! 예를 들어볼게요.

(칠판에 그림)

```
절벽 문제:

S . . . . . . . . . G  (안전한 위 경로)
C C C C C C C C C C C  (절벽)

S: 시작
G: 목표
C: 절벽 (떨어지면 큰 패널티)
```

**Q-Learning**:
- 탐험 중 가끔 절벽 근처로 떨어짐
- 하지만 업데이트는 max Q 사용 → "완벽하게 행동했다면..."
- 결과: 절벽 바로 위 최단경로 학습 (위험하지만 최적)

**SARSA**:
- 탐험 중 떨어진 경험도 학습에 반영
- "어? ε-greedy 쓰면 가끔 실수하는구나"
- 결과: 절벽에서 멀리 떨어진 안전한 경로 학습

**교사**: 표로 정리하면:

| 구분 | Q-Learning | SARSA |
|------|------------|-------|
| 학습 정책 | max (최적) | ε-greedy (현재) |
| 특성 | Off-policy | On-policy |
| 성격 | 공격적, 위험 감수 | 보수적, 안전 |
| 사용 | 시뮬레이션 | 실제 로봇 |

### [00:35-00:40] SARSA 코드 차이

**교사**: 코드로 보면 더 명확해요. (화면 공유)

**Q-Learning**:
```python
# 다음 행동 선택 안 함
best_next_q = np.max(Q[next_state])  # max!
Q[state, action] += alpha * (reward + gamma * best_next_q - Q[state, action])
```

**SARSA**:
```python
# 다음 행동 미리 선택
next_action = epsilon_greedy(Q, next_state, epsilon)
next_q = Q[next_state, next_action]  # 선택한 행동의 Q값
Q[state, action] += alpha * (reward + gamma * next_q - Q[state, action])
```

**교사**: 딱 이 차이예요! SARSA는 다음 행동을 미리 선택하고, 그 Q값을 사용합니다.

그래서 알고리즘 이름이 SARSA인 거예요:
- S: state
- A: action
- R: reward
- S: next state
- A: next action  ← 이게 필요!

## 실습 2: SARSA 비교 실험 (10분)

### [00:40-00:42] SARSA 코드 설명

**교사**: `sarsa_frozenlake.py` 파일을 봅시다.

```python
# 핵심 부분
for episode in range(num_episodes):
    state, _ = env.reset()
    action = epsilon_greedy(Q, state, epsilon)  # 첫 행동 선택
    done = False

    while not done:
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated

        # 다음 행동 선택 (중요!)
        next_action = epsilon_greedy(Q, next_state, epsilon)

        # SARSA 업데이트
        if not done:
            td_target = reward + gamma * Q[next_state, next_action]
        else:
            td_target = reward

        Q[state, action] += alpha * (td_target - Q[state, action])

        # 이미 선택한 행동 사용
        state = next_state
        action = next_action  # 다음 행동을 이미 골랐음!
```

**교사**: Q-Learning과의 차이:
1. 에피소드 시작 시 첫 행동 미리 선택
2. 매 스텝마다 다음 행동(next_action) 선택
3. 그 행동의 Q값으로 업데이트
4. 선택한 행동을 다음 스텝에서 실제로 사용

## 이론 3: ε-greedy와 하이퍼파라미터 (10분)

### [00:50-00:55] 탐험-활용 딜레마

**교사**: 다시 ε-greedy 이야기를 해볼게요.

질문: 여러분이 매일 점심 먹으러 간다고 합시다.

**선택 1**: 아는 맛집 (활용)
**선택 2**: 새로운 식당 (탐험)

계속 아는 맛집만 가면?

**학생**: 안전하지만 새로운 맛집을 못 찾아요.

**교사**: 계속 새로운 식당만 가면?

**학생**: 맛없는 곳도 많이 가겠네요.

**교사**: 정확해요! 이게 **탐험-활용 딜레마** (Exploration-Exploitation Dilemma)예요.

강화학습도 똑같아요:
- **활용**: 지금까지 배운 최선의 행동 (안전, 하지만 더 나은 방법 놓칠 수 있음)
- **탐험**: 새로운 행동 시도 (위험, 하지만 더 좋은 방법 발견 가능)

**ε-greedy 전략**:
```python
if random() < ε:
    action = 랜덤  # ε 확률로 탐험
else:
    action = argmax Q  # 1-ε 확률로 활용
```

**ε 값에 따른 행동**:
- ε = 0.0: 완전 활용 (탐험 없음) → 빠르지만 로컬 최적에 빠질 수 있음
- ε = 1.0: 완전 탐험 (랜덤) → 학습 안 됨
- ε = 0.1: 10% 탐험, 90% 활용 → 균형

### [00:55-01:00] ε-Decay 전략

**교사**: 학습 초반엔 많이 탐험하고, 후반엔 활용하는 게 좋겠죠?

그래서 **ε-decay**를 써요. (그래프 그림)

```
ε
1.0│\
   │ \___
   │     \___
   │         \___
0.0│            ───────── 에피소드
   0  200  400  600  800
```

**코드**:
```python
epsilon = 1.0
epsilon_min = 0.01
epsilon_decay = 0.995

for episode in range(num_episodes):
    # ... 학습 ...
    epsilon = max(epsilon_min, epsilon * epsilon_decay)
```

**예시 값**:
- Episode 0: ε = 1.0 (완전 탐험)
- Episode 100: ε ≈ 0.61
- Episode 300: ε ≈ 0.22
- Episode 500: ε ≈ 0.08
- Episode 700+: ε = 0.01 (최소값, 약간의 탐험 유지)

**학생**: 왜 0으로 안 하고 0.01로 유지해요?

**교사**: 좋은 질문! 완전히 0으로 하면 환경이 바뀌었을 때 적응 못 해요. 1%만 탐험을 유지하면 새로운 상황에도 조금씩 적응할 수 있어요.

## 정리 및 마무리 (5분)

### [01:22-01:25] 핵심 요약

**교사**: 오늘 배운 내용을 정리해볼게요.

**1. Model-free RL**:
- 환경의 전이확률 P를 몰라도 학습 가능
- 경험 (s, a, r, s')으로부터 학습

**2. Q-Learning**:
```
Q(s,a) ← Q(s,a) + α[R + γ·max Q(s',a') - Q(s,a)]
```
- Off-policy: 행동과 학습이 다름
- 최적 정책 학습

**3. SARSA**:
```
Q(s,a) ← Q(s,a) + α[R + γ·Q(s',a') - Q(s,a)]
```
- On-policy: 행동과 학습이 같음
- 보수적, 안전한 정책

**4. ε-Greedy**:
- ε 확률로 탐험, 1-ε 확률로 활용
- ε-decay로 점진적 감소

**5. 하이퍼파라미터**:
- α: 학습률 (0.1)
- γ: 할인율 (0.99)
- ε: 탐험률 (1.0 → 0.01)
